# Lab 1 - Cisco Router Basics

## Objective

Practice basic Cisco IOS router configuration and access security.

## Tasks Completed

- Changed the router hostname.
- Configured a console password.
- Configured local username authentication.
- Set an enable password / enable secret.
- Configured Telnet access.
- Configured SSH access.
- Added login and MOTD banners.
- Assigned an IP address to the router interface.
- Verified connectivity using `ping`.

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI

## Files

- `lab1.pkt`: Cisco Packet Tracer lab file.
